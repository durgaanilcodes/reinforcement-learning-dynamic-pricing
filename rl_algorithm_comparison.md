# Comparison of Reinforcement Learning Algorithms for Dynamic Pricing

## Objective

Select the most suitable reinforcement learning algorithm for a dynamic pricing system.

---

## Evaluation Criteria

- Learning speed
- Scalability
- Complexity
- Computational cost
- Suitability for dynamic pricing

---

| Feature | Q-Learning | SARSA | DQN |
|---------|------------|--------|-----|
| Easy to implement | Yes | Yes | Moderate |
| Uses Q-Table | Yes | Yes | No |
| Uses Neural Network | No | No | Yes |
| Suitable for large datasets | No | No | Yes |
| Computational Cost | Low | Low | High |
| Scalability | Medium | Medium | High |

---

## Recommended Algorithm

Q-Learning is recommended for initial implementation because it is simple and effective.

DQN can be adopted later when the environment becomes more complex.
